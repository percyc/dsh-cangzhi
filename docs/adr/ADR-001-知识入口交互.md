# ADR-001：知识入口采用轻量 Popover

- 状态：已采纳
- 日期：2026-08-31

## 背景

此前新建对话页面直接展示较大的藏知区域，同时存在首页入口、知识抽屉和管理中心等重复入口。用户难以判断当前对话是否使用藏知，也不容易选择知识空间。

## 决策

新建对话只显示紧凑的藏知入口。点击后打开 Popover，集中提供：

- 服务连接状态；
- 知识空间选择；
- 知识能力偏好；
- 登录、连接和断开；
- 资料抽屉与管理中心入口。

输入区和会话头部保留轻量入口作为可发现性和旧 DSH 的降级路径，不再常驻展开管理界面。

## 取舍

- 优点：减少视觉占用、入口统一、功能仍然可达。
- 代价：高级资料管理需要多一次点击；Popover 需要处理定位、键盘关闭和窄屏边界。

## 后续

能力开关现已通过 DSH `sessionId` 写入 Host 的 Agent 作用域，Popover 不再使用“知识能力偏好”这一抽象术语；浏览器存储仅恢复显示状态，不能替代 Host 策略。
