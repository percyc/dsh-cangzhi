# ADR-013：管理员登录与检索 PAT 保持独立

- 日期：2026-09-30
- 状态：已采纳，待运行验收

## 背景

藏知管理员会话固定 12 小时失效，而 DSH 的 `CANGZHI_TOKEN` 长期保存。工作台登录流程目前每次成功都会新建并写入 PAT，即使旧 PAT 仍有效。

## 决策

1. 工作台登录提供未默认勾选的“记住此浏览器”，把选择传给藏知 `/api/auth/login`，由藏知服务端实现续期。插件不保存管理员密码或管理员 Cookie。
2. 登录成功后先通过 Host 检查已保存 PAT 是否仍能访问藏知知识范围。有效时直接复用；缺失或失效时才签发只读/检索/问答 PAT 并保存至 DSH credentials。
3. 管理页面的登录状态与模型工具的连接状态分开显示。若 PAT 创建失败，已成功的管理员登录不被描述为失败，用户可在工作台重试连接。

## 验收

- 老登录请求继续使用藏知默认 12 小时会话；勾选选择传递到上游。
- 已有效 PAT 不产生新的访问令牌；失效时才重新创建。
- 退出或断开仍具有原来的明确语义；管理登录不赋予模型管理权限。
