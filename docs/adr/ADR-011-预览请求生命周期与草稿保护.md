# ADR-011：预览请求生命周期与草稿保护

- 日期：2026-09-07
- 状态：已采纳；浏览器交互验收待完成

## 决策

- 文档、证据和表格分页共享 latest-request 生命周期。新选择取消旧请求，读取正文后再次验证请求身份；旧成功、错误和 finally 都不得覆盖新选择。
- 关闭、卸载、知识空间变更使预览失效。打开面板首次载入资料列表不取消同次点击触发的证据预览。
- 每次预览从 Host 确认会话空间，并在该请求链中固定空间头；不以 Cookie 猜测当前对话空间。
- 准备提问保留原文字并追加提示，重复相同提示不重复追加。DSH 当前 public inputActions 只有 setDraft 整段替换；草稿包含引用 occurrence 或不是 plain 阶段时拒绝重写并反馈，保护结构化编辑状态。不自动发送。

## 历史证据空间边界

目前 EvidenceLink 与持久化工具结果提取链没有可靠的空间身份，不能仅凭当前会话空间还原旧证据来源。本轮明确提示仅在当前空间核验版本，不自动跨空间搜索。

后续需在 Host 调用时记录可信空间身份，并随工具结果持久化和证据提取传递；去重键也必须包含空间。旧记录保持“空间未知”，不能回填成当前空间。该元数据迁移尚未实施，本 ADR 不表示历史证据归属问题已解决。
