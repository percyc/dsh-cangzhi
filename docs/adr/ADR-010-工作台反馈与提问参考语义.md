# ADR-010：工作台反馈与提问参考语义

- 日期：2026-09-07
- 状态：已采纳，浏览器交互验收待完成

## 决策

- 保持轻量入口与 360–760px 单一拖拽布局，不重新加入档位或全屏按钮；补充方向键、Home/End 调宽和键盘焦点。
- 搜索框草稿与已完成搜索分离：仅成功提交后切换结果，清除搜索返回最近资料；错误保留原列表并提示，避免输入即出现假空结果。
- “加入对话”改为“准备提问”：行为仍是填写输入框，不自动发送、不自动开启藏知、不宣称模型已读。参考资料列表是临时记录，综合提问携带实际文档标识。
- 工作台主体文字以 13px、辅助文字以 12px 为目标，分页允许换行；网络失败必须结束处理中状态并显示提示。

## 限制

本轮不新增自动检索或会话附件协议。输入框草稿填写仍复用现有 DSH 接口；真实浏览器、快速连续切换证据的并发验收仍须单独进行。
